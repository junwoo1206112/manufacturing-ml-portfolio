# 페이즈 2: ML 엔진 고도화

## 목표
품질 예측 및 예측 정비 모델의 성능을 향상시키고, 모델 관리 체계를 구축한다.

## 체크리스트

### 2.1 품질 예측 모델 고도화
- [ ] 모델 비교 실험
  - [ ] Random Forest (기존)
  - [ ] Gradient Boosting (XGBoost, LightGBM)
  - [ ] SVM (커널 튜닝)
  - [ ] 로지스틱 회귀 (베이스라인)
- [ ] 하이퍼파라미터 튜닝
  - [ ] GridSearchCV 또는 RandomizedSearchCV
  - [ ] 교차 검증 전략 (StratifiedKFold)
- [ ] 모델 앙서블
  - [ ] Voting Classifier
  - [ ] Stacking (메타 모델)
- [ ] 특성 엔지니어링 확장
  - [ ] 시계열 특성 (이동평균, 표준편차)
  - [ ] 교차 특성 (온도 × 진동)
  - [ ] 공정 단계별 집계 특성

### 2.2 예측 정비 모델 개발
- [ ] 설비 수명 예측 모델
  - [ ] 회귀 모델 (잔여 수명 예측)
  - [ ] 생존 분석 (고장 확률)
- [ ] 이상 탐지 시스템
  - [ ] Isolation Forest
  - [ ] Autoencoder 기반 이상탐지
- [ ] 잔여 수명 예측 (RUL)
  - [ ] 센서 데이터 기반 RUL 추정

### 2.3 모델 관리
- [ ] 모델 버전 관리 (`src/model_manager.py`)
  - [ ] 모델 저장/로드 (pickle → joblib)
  - [ ] 메타데이터 기록 (정확도, 학습 데이터 크기, 하이퍼파라미터)
  - [ ] 모델 비교 리포트 생성
- [ ] 모델 평가 대시보드
  - [ ] 혼동행렬 시각화
  - [ ] ROC-AUC 곡선
  - [ ] 특성 중요도 시각화

### 2.4 테스트
- [ ] 모델 학습 테스트 (`tests/test_model.py`)
  - [ ] 학습 성공 여부
  - [ ] 예측 결과 형식 검증
  - [ ] 모델 저장/로드 일관성
- [ ] 성능 기준선 설정
  - [ ] Accuracy > 85%
  - [ ] Recall > 80% (불량 샘플)
  - [ ] Precision > 75%

## 파일 구조 변경

```
src/
├── quality_predictor.py      # 기존 + 앙서블 확장
├── maintenance_predictor.py  # 신규: 고급 예측 정비
├── anomaly_detector.py       # 신규: 이상 탐지
├── model_manager.py          # 신규: 모델 관리
└── hyperparameter_tuner.py   # 신규: 하이퍼파라미터 튜닝

tests/
├── test_model.py             # 신규: 모델 테스트
└── test_data.py              # 신규: 데이터 테스트
```

## 완료 기준
1. 최고 모델 정확도 85% 이상 달성
2. 3개 이상 모델 비교 리포트 생성
3. 모델 버전 관리 가능
4. 모든 테스트 통과
