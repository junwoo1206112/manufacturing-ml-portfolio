## 빠른 참조

### 현재 파일 구조
```
manufacturing-simulation-portfolio/
├── README.md
├── requirements.txt
├── main.py
├── .gitignore
├── data/                  # 생성 데이터
├── src/                   # 핵심 소스
│   ├── data_analyzer.py
│   ├── quality_predictor.py
│   ├── predictive_maintenance.py
│   └── visualizer.py
├── models/                # 학습된 모델
├── visualizations/        # 시각화 결과
├── dashboard/             # 웹 대시보드
│   └── app.py
└── documents/             # 프로젝트 문서
    ├── 00_프로젝트_분석과_방향성.md
    ├── 01_페이즈1_데이터_파운데이션.md
    ├── 02_페이즈2_ML_엔진_고도화.md
    ├── 03_페이즈3_대시보드_고도화.md
    ├── 04_페이즈4_프로덕션_준비.md
    ├── 05_페이즈5_포트폴리오_마무리.md
    └── 06_마스터_체크리스트.md
```

### 실행 명령어
```bash
# 데이터 생성 + 모델 학습 + 시각화
python main.py

# 대시보드 실행
python dashboard/app.py

# 테스트 실행
pytest tests/ -v

# 코드 검사
flake8 src/ dashboard/
black --check src/ dashboard/
```
