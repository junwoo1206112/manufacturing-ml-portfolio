# 프로젝트 분석 및 방향성

## 현재 상태 진단

### 장점
- 명확한 목적: 소르테크 지원용 포트폴리오
- 핵심 기능 구현 완료: 데이터 생성 → 분석 → 예측 → 시각화 → 대시보드
- 프로젝트 구조가 체계적
- 기술 스택 선정 적절 (Python, Scikit-learn, Flask)

### 개선 필요 사항

| 영역 | 현재 | 목표 |
|------|------|------|
| 데이터 | 랜덤 생성 (실제 공정 패턴 부재) | 물리적 기반 시뮬레이션 |
| ML 모델 | 단일 RandomForest | 앙상블 + 하이퍼파라미터 튜닝 |
| 대시보드 | 정적 HTML, 하드코딩 데이터 | 실시간 업데이트, 인터랙티브 |
| 테스트 | 없음 | 단위/통합 테스트 |
| 설정 | 하드코딩 | 환경별 설정 관리 |
| 에러 처리 | 최소 | 견고한 에러 핸들링 |
| 문서화 | README만 | API 문서, 아키텍처 도식 |

## 프로젝트 방향성

### 비전
"제조 공정 데이터 기반 의사결정 지원 시스템"으로서의 실제 활용 가능성을 보여주는 포트폴리오

### 핵심 가치 제안
1. **데이터 기반 품질 관리**: 공정 데이터를 활용한 불량 예측 및 원인 분석
2. **예측 정비**: 설비 고장 예측을 통한 다운타임 최소화
3. **실시간 모니터링**: 대시보드를 통한 공정 상태 실시간 파악
4. **의사결정 지원**: 경영진/엔지니어를 위한 인사이트 도출

### 기술적 깊이
- 심층 학습 없이도 고급 분석 가능 (앙서블, 시계열, 이상탐지)
- 배포 가능 수준의 코드 품질
- 면접에서 설명 가능한 명확한 설계 의사결정
