# 페이즈 3: 대시보드 고도화

## 목표
 Flask 대시보드를 인터랙티브하고 실시간 업데이트가 가능한 수준으로 고도화한다.

## 체크리스트

### 3.1 대시보드 UI/UX 개선
- [ ] 프론트엔드 프레임워크 도입 검토
  - [ ] Option A: Bootstrap + Chart.js (경량)
  - [ ] Option B: Streamlit (빠른 개발)
  - [ ] Option C: Dash by Plotly (인터랙티브)
- [ ] 반응형 디자인 적용
  - [ ] 모바일/태블릿 호환
  - [ ] 다크모드 지원
- [ ] 차트 고도화
  - [ ] 시계열 차트 (실시간 업데이트)
  - [ ] 지도 기반 설비 배치도
  - [ ] 히스토그램 및 분포 차트

### 3.2 실시간 모니터링
- [ ] WebSocket 또는 polling 기반 실시간 업데이트
- [ ] 센서 데이터 스트리밍 시뮬레이션
- [ ] 알림 시스템
  - [ ] 불량률 임계값 초과 알림
  - [ ] 설비 이상 상태 알림
  - [ ] 브라우저 푸시 알림

### 3.3 API 강화
- [ ] RESTful API 구조화 (`dashboard/api.py`)
  - [ ] `/api/v1/summary` - 요약 통계
  - [ ] `/api/v1/equipment` - 설비 상태
  - [ `/api/v1/predictions` - 예측 결과
  - [ ] `/api/v1/alerts` - 알림 목록
- [ ] API 문서화 (Swagger 또는 Markdown)
- [ ] 에러 핸들링 및 응답 형식 통일

### 3.4 데이터 시각화 확장
- [ ] 대시보드 요약 차트 추가
  - [ ] KPI 카드 (불량률, 가동률, 효율성)
  - [ ] 트렌드 차트 (일/주/월별)
  - [ ] 비교 차트 (라인별, 기간별)
- [ ] 인터랙티브 필터
  - [ ] 날짜 범위 선택
  - [ ] 라인별 필터
  - [ ] 설비별 필터

## 파일 구조 변경

```
dashboard/
├── app.py                    # 기존 + 라우트 분리
├── api.py                    # 신규: API 엔드포인트
├── static/
│   ├── css/
│   │   └── style.css         # 신규: 스타일시트
│   └── js/
│       └── dashboard.js      # 신규: 클라이언트 로직
└── templates/
    └── index.html            # 신규: HTML 템플릿
```

## 완료 기준
1. 대시보드 로드 시간 3초 이내
2. 실시간 업데이트 정상 동작
3. 모바일에서도 사용 가능
4. API 문서 완성
