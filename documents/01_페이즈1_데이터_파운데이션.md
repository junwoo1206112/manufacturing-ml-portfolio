# 페이즈 1: 데이터 파운데이션

## 목표
현실적인 제조 공정 데이터를 생성하고, 데이터 품질 관리 체계를 구축한다.

## 체크리스트

### 1.1 데이터 생성 고도화
- [ ] 물리적 기반 센서 데이터 시뮬레이션
  - [ ] 온도: 일일 주기 + 계절 변화 + 노이즈
  - [ ] 압력: 공정별 상이한 정상 범위
  - [ ] 진동: 설비 수명에 따른 증가 추세
  - [ ] 습도: 외부 환경 연동 시뮬레이션
- [ ] 공정별 차별화된 데이터 패턴
  - [ ] 라인 A: 고온 공정 (전자부품)
  - [ ] 라인 B: 정밀 공정 (기계부품)
  - [ ] 라인 C: 대량 생산 (소비재)
- [ ] 결함 패턴 시뮬레이션
  - [ ] 온도-불량 상관관계 강화
  - [ ] 진동-불량 상관관계 강화
  - [ ] 피로 누적에 따른 불량 증가
  - [ ] 운영자 스킬 차이 반영

### 1.2 데이터 품질 관리
- [ ] 데이터 검증 모듈 생성 (`src/data_validator.py`)
  - [ ] 이상치 탐지 (IQR, Z-score)
  - [ ] 결측값 처리 전략
  - [ ] 데이터 무결성 검사
- [ ] 데이터 전처리 파이프라인 (`src/data_pipeline.py`)
  - [ ] 스케일링 (StandardScaler, MinMaxScaler)
  - [ ] 인코딩 (One-Hot, Label)
  - [ ] 피처 엔지니어링

### 1.3 테스트 데이터셋
- [ ] 학습/검증/테스트 분할 (70/15/15)
- [ ] 클래스 불균형 처리 (SMOTE 또는 클래스 가중치)
- [ ] 시계열 분할 옵션 (시간 기반 분할)

## 파일 구조 변경

```
src/
├── data_analyzer.py          # 기존 + 개선
├── data_validator.py         # 신규: 데이터 검증
├── data_pipeline.py          # 신규: 전처리 파이프라인
├── data_generator.py         # 신규: 고급 데이터 생성
└── config.py                 # 신규: 설정 관리
```

## 완료 기준
1. `python -m src.data_generator` 실행 시 현실적인 데이터 5000건 생성
2. 데이터 검증 통과율 95% 이상
3. 전처리된 데이터가 모델 학습에 사용 가능
